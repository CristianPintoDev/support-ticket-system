# 🎫 Support Ticket System (In Progress)

API REST desarrollada como proyecto de aprendizaje y puesta a prueba de conocimientos, orientada a la creación de un **sistema de tickets de soporte técnico**.

El proyecto se encuentra actualmente **en desarrollo activo** y está pensado para crecer de forma progresiva, aplicando buenas prácticas de backend.

---

## 📌 Objetivo del proyecto

El objetivo es construir un sistema que permita:

- Gestión de usuarios
- Autenticación segura
- Creación y seguimiento de tickets de soporte
- Comunicación entre clientes y personal de soporte

Este proyecto se utiliza como práctica para afianzar conceptos de backend y arquitectura de APIs.

---

## 🧱 Estado actual

🚧 Gestión de usuarios  
🚧 Autenticación con JWT  
🚧 Sistema de tickets (en desarrollo)
